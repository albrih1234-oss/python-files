# Downloader Cmder

A lightweight command-line tool written in Python that downloads YouTube videos from a pasted link, built with [yt-dlp](https://github.com/yt-dlp/yt-dlp).

## Features

- Download a YouTube video by pasting its link
- Simple terminal interface, no GUI required

## Download

1. Go to the [Releases](../../releases) page.
2. Download the latest version of [Downloader_Cmder, e.g. Downloader_Cmder.exe].
3. Run it and follow the instructions in the terminal.

## Usage

Run the program, paste the YouTube video link when prompted, and the download will start.

## Built With

- Python
- yt-dlp

## Notes

This project was created for learning purposes, to practice Python scripting and building command-line applications. Please respect YouTube's terms of service and copyright when downloading content.
